## 🏛️ Происхождение, Форк и Модификации Seclib

Odin представляет собой независимый форк открытого проекта **God's Eye View**, созданного Билавалом Сидху и Самехом Хамисом (Halfpixel).

### Зачем создан этот форк

Оригинальный проект продемонстрировал, что открытые геопространственные сигналы (ADS-B, AIS, спутниковые элементы SGP4, сейсмографы, дорожные камеры, метеорадары) можно свести в единую интерактивную 3D-среду.

**Seclib** создала форк **Odin** для адаптации платформы к высоким требованиям цифрового суверенитета, защищённости и конфиденциальности:
- **Суверенный локальный ИИ:** Полное отвязывание интеллектуальных функций от закрытых облачных API в пользу локального выполнения на платформе **ETHAN**.
- **Контейнерная изоляция:** Ограничение сетевых интерфейсов строго локальным контуром (loopback) и ужесточение политик проксирования.
- **Глобальная многоязычность:** Полноценная интернационализация интерфейса на шесть языков, включая полноценную поддержку арабского языка с отзеркаливанием интерфейса (RTL).
- **Юридическая чистота данных:** Чёткое разграничение исходного кода под лицензией MIT и сторонних наборов данных с ограничениями на коммерческое использование.

### Изменения, внесённые Seclib

Все доработки сохраняют обратную совместимость с форматами сцен God's Eye View:

1. **Бренд и управление:** Продукт переименован в **Odin**, репозиторий сопровождается организацией Seclib; оригинальные авторские права сохранены в [NOTICE.md](NOTICE.md).
2. **Интеграция с платформой ETHAN:**
   - Нативная поддержка взаимодействия с локальными моделями ETHAN (`core/llm` / `interfaces/api`) через переменные `GEV_ETHAN_API_URL` и `GEV_ETHAN_API_KEY`/`GEV_ETHAN_TOKEN`.
   - Тактическая сводка HUD генерируется полностью на мощностях локального кластера (Ollama / vLLM / ETHAN) без исходящего трафика во внешние облака.
3. **Безопасная конфигурация Docker и сети:**
   - В `compose.yaml` порт по умолчанию привязан строго к `127.0.0.1:4173`, что исключает случайную публикацию ключей в локальной сети (LAN).
   - Принудительная проверка HTTP-заголовков Host через `GEV_ALLOWED_HOSTS` для предотвращения атак DNS Rebinding.
   - Отключение по умолчанию небезопасных туннелей и непроверенных шлюзов.
4. **Многоязычная архитектура (i18n):**
   - Полные каталоги переводов для **английского** (`en`), **французского** (`fr`), **русского** (`ru`), **испанского** (`es`), **китайского упрощённого** (`zh-CN`), **японского** (`ja`) и **арабского** (`ar`) языков.
   - Двунаправленный движок верстки с отзеркаливанием элементов для арабского языка (RTL).
5. **Юридический аудит лицензий:**
   - Выделение наборов данных с некоммерческими (NC) лицензиями (`TeleGeography`, `Bhote Koshi`).
   - Регламент ответственного сообщения об уязвимостях в [SECURITY.md](SECURITY.md).

## ⚡ Быстрый Старт

Запуск Odin возможен **без регистрации и без API-ключей**. По умолчанию загружаются снимки Esri и свободная карта высот. 18 из 20 слоёв доступны сразу.

### Вариант 1 — Локальный Node.js (Для разработчиков)

Требуется **Node.js 24 LTS (24.14.0+) или 26.x**.

```bash
# 1. Клонирование репозитория
git clone https://github.com/seclib/odin.git
cd odin

# 2. Установка зависимостей
npm ci

# 3. Диагностика готовности окружения
npm run doctor

# 4. Запуск сервера разработки
npm run dev
```

Откройте в браузере: **`http://localhost:4173`**.

### Вариант 2 — Docker Compose (Для изолированного запуска)

Требуется Docker и Docker Compose. Установка Node.js на хост не требуется.

```bash
# 1. Клонирование репозитория
git clone https://github.com/seclib/odin.git
cd odin

# 2. Запуск от имени текущего пользователя хоста
env UID=$(id -u) GID=$(id -g) docker compose up
```

Откройте **`http://localhost:4173`**.
- Конфигурации и кэш (`.env`, `.gev-cache/`, `.gev-logs/`) сохраняются на вашем хосте.
- Сервер изолирован на `127.0.0.1:4173` для предотвращения несанкционированного доступа из локальной сети.

### Вариант 3 — Лаунчер Pinokio

1. Установите [Pinokio](https://desktop.pinokio.co/) версии 8.2 или новее.
2. Найдите приложение `odin` или укажите URL репозитория.
3. Нажмите **Install**, затем **Start**.

## 🛠️ Настройка и Устранение Неполадок

### Настройка через интерфейс (Provider Settings)

Нажмите плашку **POWER UP** в правом нижнем углу интерфейса (или откройте `http://localhost:4173/?setup=1`). Здесь вы можете безопасно указать дополнительные API-ключи, которые сохранятся в ваш файл `.env`.

### Переменные окружения (`.env`)

Для автоматизации скопируйте шаблон:

```bash
cp .env.example .env
```

Ключевые параметры:
- `PORT=4173` — HTTP-порт веб-сервера.
- `HOST=127.0.0.1` — Сетевой интерфейс (`0.0.0.0` только при осознанной раздаче в LAN).
- `GEV_ALLOWED_HOSTS=localhost,127.0.0.1` — Разрешённые заголовки Host (защита от DNS Rebinding).
- `GEV_ETHAN_API_URL=http://localhost:8000` — Адрес локального бэкенда ETHAN.
- `GEV_ETHAN_API_KEY=` — Токен аутентификации для ETHAN.
- `OPENAI_API_KEY=` — Ключ OpenAI для облачного голоса и сводок.
- `CESIUM_ION_TOKEN=` — Токен Cesium ion для фотореалистичных 3D-городов Google.
- `GOOGLE_MAPS_API_KEY=` — Ключ Google Maps для прямого доступа к 3D-плиткам и Street View.
- `AISSTREAM_API_KEY=` — Бесплатный ключ для отслеживания морских судов по всему миру.

### Решение проблем

1. **Ошибка прав доступа в Docker (`EACCES` к файлам `.env` или `.gev-cache`):**
   - Причина: Контейнер был запущен из-под `root`.
   - Решение: Запускайте через `env UID=$(id -u) GID=$(id -g) docker compose up`.
2. **Низкая частота кадров / рывки в 3D:**
   - Причина: Отключено аппаратное ускорение в браузере или WebGL работает через софтверный рендерер CPU.
   - Решение: Включите аппаратное ускорение в настройках браузера, проверьте статус на странице `chrome://gpu` или `about:support`.
3. **Панель настроек сообщает «Loopback Only»:**
   - Причина: Доступ осуществляется через внешний IP или обратный прокси.
   - Решение: Пропишите ключи напрямую в `.env` или настройте доверие через `GEV_KEY_SETUP_TRUSTED_PEERS` (см. [SECURITY.md](SECURITY.md)).
4. **Пустые слои трафика или дорожных камер ALPR:**
   - Причина: Лимиты публичных серверов Overpass (OpenStreetMap). Встроенный кэширующий прокси снижает нагрузку; перезапустите `npm run dev`.

## 🤖 ИИ-Возможности: Локальный ETHAN и Облачные Модели

Odin обеспечивает аналитический синтез ситуации, ответы на вопросы об объектах и голосовое управление.

### 1. Суверенный локальный интеллект через ETHAN (Доработка Seclib)

Для замкнутых и защищённых контуров Odin штатно интегрируется с **ETHAN**:
- Тактический обзор в HUD обращается к локальному сервису ETHAN (`GEV_ETHAN_API_URL=http://localhost:8000`).
- Координаты, высота, активные слои и обнаруженные военные контакты форматируются в разведывательную сводку и анализируются локально.
- **Никакой утечки данных:** Запросы, телеметрия и видеопотоки не покидают вашу инфраструктуру.

### 2. Облачный голосовой интерфейс (OpenAI)

- Подключение к **OpenAI Realtime API** по WebSocket с минимальной задержкой.
- **Финансовые лимиты:** Жёсткий потолок расходов **$5.00** за сеанс с предупреждением на $2.00 и динамическим счётчиком затрат.
- 30 встроенных команд голосового управления:
  - _Навигация:_ «Перенеси меня в Токио», «Облети гавань по кругу».
  - _Разметка:_ «Обведи штат Техас», «Измерь расстояние от Парижа до Рима».
  - _Анализ:_ «Сколько танкеров сейчас в проливе Ла-Манш?», «Покажи военные самолёты выше 30 000 футов».
  - _Управление:_ «Включи режим ночного видения», «Войди в кабину ближайшего борта».

### 3. Сервер Model Context Protocol (MCP)

Odin может выступать в роли MCP-сервера, позволяя сторонним агентам (Claude Desktop, Codex, ChatGPT) управлять глобусом и считывать телеметрию программно. См. [docs/MCP_SETUP.md](docs/MCP_SETUP.md).

## 🔒 Конфиденциальность, Модель Безопасности и Сеть

В архитектуру Odin заложены строгие принципы информационной безопасности:

### 1. Локальное выполнение без телеметрии
- В Odin **полностью отсутствуют телеметрия, трекеры и системы аналитики**.
- Никакие диагностические данные не отправляются ни в Seclib, ни создателям оригинального проекта.
- Всё выполняется в вашем браузере, который обращается только к вашему серверу и явно включённым поставщикам данных.

### 2. Безопасное проксирование секретных ключей
Секретные ключи (`OPENAI_API_KEY`, `AISSTREAM_API_KEY`, `OPENSKY_CLIENT_SECRET`, `GEV_ETHAN_API_KEY`) **никогда не попадают в браузер**.
- Веб-интерфейс обращается только к локальным прокси-эндпоинтам (`/api/vessels`, `/api/flights`, `/api/realtime/token`).
- Для WebSocket-соединений генерируются кратковременные одноразовые токены.
- Серверные прокси защищены от SSRF, ограничивают размер ответов и контролируют таймауты.

### 3. Клиентские ключи и обязательные ограничения
Три ключа передаются непосредственно в WebGL-движок браузера:
- `GOOGLE_MAPS_API_KEY` (3D-плитки Google и Maps JS API)
- `CESIUM_ION_TOKEN` (3D-плитки и рельеф Cesium ion)
- `MAPILLARY_CLIENT_TOKEN` (Панорамы Mapillary)

> [!WARNING]
> Так как эти ключи видны в консоли браузера, вы **ОБЯЗАНЫ** настроить ограничения в панелях провайдеров:
> - **Google Cloud Console:** Ограничение по HTTP Referrer (`http://localhost:4173/*` или ваш домен) и ограничение по API (только **Map Tiles API** и **Maps JavaScript API**).
> - **Cesium ion:** Ограничение по домену источника и права только на чтение (`assets:read`).

### 4. Этические ограничения
Odin предназначен для мониторинга физических объектов, техники, природных явлений и сенсорных сетей.
- **Принцип неприкосновенности частной жизни:** В Odin принципиально отсутствуют и не будут приниматься функции распознавания лиц, пробива автомобильных номеров по базам владельцев или персональной слежки за людьми.

## 📡 Источники данных и внешние зависимости

Odin объединяет **открытые данные из публичных источников** с **локальным рендерингом**. Лицензия MIT покрывает только программный код — она не распространяется на сторонние данные или визуальные активы. Каждый провайдер сохраняет свои собственные лицензии и условия.

### Источники в реальном времени (загружаются во время работы)

| Источник | Используется для | Лицензия / условия |
| --- | --- | --- |
| NOAA GFS (ветер) | Глобальная модель ветра | Общедоступная (данные NOAA на AWS) |
| ECMWF IFS (ветер) | Альтернативная модель ветра | CC BY 4.0 + Условия использования ECMWF |
| NOAA nowCOAST | Радар, облака в инфракрасном диапазоне, молнии | Общедоступная |
| OpenSky Network | Позиции ADS-B (самолёты) | Бесплатный уровень ; условия применяются |
| adsb.lol | Фильтрованный ADS-B (военные, гос. регистрации) | Бесплатно ; условия применяются |
| AISStream.io | Морская навигация судов | Бесплатный уровень ; условия применяются |
| CelesTrak | Элементы орбит (TLE) | Данные NASA (публичные) |
| USGS Seismology | Глобальные данных о землятрясениях | Общедоступная |
| NASA FIRMS | Обнаружение активных пожаров | Общедоступная (запрашивается атрибуция) |
| OpenStreetMap | Дорожная сеть, велопарки, транспорт | ODbL 1.0 |
| TomTom Flow | Скорость движения | Условия использования (см. `docs/OSRM-FOSSGIS.md`) |
| Mapillary / KartaView / Panoramax | Изображения на уровне улиц | Смешанные лицензии ; см. DATA_SOURCES.md |
| Radio Browser | Радиостанции с геолокацией | Бесплатно ; условия применяются |
| Потоки GTFS-Realtime | Позиции транспорта в реальном времени | Условия операторов |
| Потоки GBFS | Доступность велосипедов | Условия операторов (см. DATA_SOURCES.md) |
| OSRM / FOSSGIS | Маршрутизация и навигация | Бесплатно ; ODbL |
| Launch Library 2 | Расписание запусков ракет | Бесплатный уровень ; условия применяются |
| Карта подводных кабелей TeleGeography (в комплекте) | Визуализация карты кабелей | [CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/) — Некоммерческое использование + ShareAlike |

### Встроенные данные (хранятся в репозитории)

- **`src/data/local_data/`** — наборы данных (карта кабелей TeleGeography, извлечения OpenStreetMap, изображения событий и т. д.)
- **`public/models/`** — 3D-модели с индивидуальными лицензиями (см. [`public/models/README.md`](public/models/README.md))

### Внешние зависимости

- **npm-пакеты** — задокументированы в [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md) и `package-lock.json`
- **Cesium ion** — опциональный токен доступа для тайлов 3D ; бесплатный уровень доступен
- **Google Maps Platform** — опциональный ключ API для тайлов 3D и Street View
- **Облачные провайдеры ИИ** — OpenAI (опционально) для голоса в облаке и суммаризации сцены ; локальный ETHAN для суверенных альтернатив

## 🤝 Участие в Разработке, Сообщение об Ошибках и Обновления

### Участие в разработке

Мы приветствуем доработки, повышающие стабильность, скорость рендеринга и качество переводов:
1. Запустите тесты: `npm test`.
2. Проверьте каталоги локализации: `npm run i18n`.
3. Убедитесь в соблюдении модульных границ: `npm run check:boundaries`.
4. Ознакомьтесь с регламентом в [CONTRIBUTING.md](CONTRIBUTING.md).

### Сообщение об уязвимостях

Сообщения о проблемах безопасности принимаются **строго конфиденциально**:
- Создайте приватный Security Advisory на GitHub: `https://github.com/seclib/odin/security/advisories/new`
- Либо напишите в службу безопасности: **security@seclib.org**.
- Не создавайте публичные issue для критических уязвимостей. Подтверждение ответа — в течение 48 часов.

### Обновление Odin

Для обновления до актуальной версии:

```bash
# При установке через Git / Node.js:
git pull origin main
npm ci
npm test

# При установке через Docker Compose:
git pull origin main
docker compose down -v
docker compose up --build
```
