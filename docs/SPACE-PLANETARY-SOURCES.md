## Source rules for further integrations

- Keep secrets out of the browser. This first Mars WMTS layer has no key; if a later source needs a free key, store it in optional server configuration and do not make it a hard dependency.
- Do not label an endpoint integrated/available based only on project code or documentation. Record live request date, result and exact request scope.
- Prefer bounded viewport/search requests, cache only as source terms permit, and do not mirror a dataset without explicit redistribution terms.
- For every visible orbit or image keep data provenance, retrieval/update time, source record, product-specific credit/license and an explicit unavailable/uncertain state.
